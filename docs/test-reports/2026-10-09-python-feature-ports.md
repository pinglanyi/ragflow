# Python 官方功能移植验收记录

日期：2026-10-09。分支：`chunk-mm`。范围来自用户批准的完整功能清单。

## 功能与启用方式

| 功能 | 交付行为 | 启用与边界 |
| --- | --- | --- |
| 元数据文档选择 | Agentic Search 可按真实字段筛选，支持无查询词选择；原带查询词路径保留 | 已有文档元数据可直接使用；无匹配不会扩大到全库 |
| 声明标题索引 | 首个页面任务从首个非空块中提取有界标题词，加入标题关键词 | 新解析生效；存量文档需重解析，不自动触发生产重解析；正文、文件名和向量输入保留 |
| grep/BM25 | 保留原 grep 语义与 keyword-only 检索，补齐知识库授权、空文档范围和零预算约束 | 自动生效，无需改模型配置 |
| 稳定网页引用 | 四个原搜索连接器及 Search1API 共享确定性网页/片段标识，重复调用可一致去重 | 原 URL、正文、评分与顺序保留 |
| 全局视觉增强 | Parser 表单提供继承、启用、禁用及全局视觉模型选择 | 缺省继承原设置；启用且未选模型时用租户默认视觉模型；显式无效模型保留原提取文本，不静默改绑 |
| PDF 页码 | Plain Text、VLM、DeepDOC 支持多范围、重叠合并及任务范围交集，修正 DeepDOC 小窗口全局页码 | 外部 OCR 的局部页码不支持；界面隐藏并在保存时剔除，直接 API 传入则明确报错 |
| Search1API | 前端选择与独立密钥保存、Python 请求实现、稳定引用 | 需配置有效密钥；错误响应不泄漏密钥 |
| Opper | Python chat/vision/embedding 驱动、元信息与目录 | 需配置凭据及服务端实际可用模型 |
| SiliconFlow | 更新实际 Python 模型目录，合并保留旧国内/国际模型名称，接入音频转写 | 保留区域连接地址与旧绑定；OCR 模型沿用现有 vision 接口，不代表新增专用 PDF OCR 协议 |

不迁移 Go 后端、队列或数据库，不修改生产模型凭据。自定义 full/smart 路径、模板编辑及旧模型绑定保留。

## 七、本轮缺口实现与重点对照结果

完整提交登记表现在包含每个提交的实际影响文件、Python/前端/Go 等范围、对照状态和 Python 证据。232 个提交中，22 个重点提交完成了代码路径对照（包括明确标记的部分对照），13 个仅文档变化归类，197 个保留“待语义对照”；没有将初筛自动当成等价性验收。

新增 Search1APISearch / Search1APICrawl 可作为独立工作流节点或 Agent 工具。搜索支持 general/news、相应服务列表、时间范围、最多 50 条结果和稳定证据 ID；抓取返回页面 JSON。前端包含节点菜单、配置表单、初值、输出、日志名、图标、中英文及导出密钥清理。凭据仅由节点配置提供，模型无法通过参数覆盖。失败写入 _ERROR；调用有超时和取消检查，不自动重试计费请求。原聊天六条结果接口保留。

重点对照确认并修复两项实际缺陷：

1. embedding 公共调用缺少返回数量校验；在 LLMBundle.encode 和 Base._batched_encode 分别补齐总数与单批次检查，避免不同批次数量错误相互抵消。
